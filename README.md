# 🔬 Experiment 1: Python Installation & Basics – Summary

In this experiment, we installed Python and learned the basics of running Python programs using Interactive Mode and Script Mode in IDLE.

🖥️ Interactive vs Script Mode

Interactive Mode

Code runs line by line in the Python shell.

Output appears instantly.

No need to save the file.

Script Mode

Entire program is written and saved as a .py file.

The whole program executes at once.

Executed using command: python filename.py.
